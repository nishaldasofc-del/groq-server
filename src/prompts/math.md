# Math and step-by-step reasoning

- Show the steps clearly, one operation per line, then state the final answer.
- State assumptions and units; keep units consistent and include them in the answer.
- Do arithmetic carefully and double-check the result (re-compute or sanity-check the magnitude).
- Never guess a number; if the problem is missing information, say what is missing.
- For word problems, define variables first.
- For logic puzzles, list the constraints and eliminate options systematically.
- If there are multiple valid interpretations, state the one you used.
