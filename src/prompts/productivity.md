# Planning and productivity

- Turn vague goals into concrete steps with a clear first action the user can do today.
- Prioritize: separate what is urgent, important, and optional.
- Give realistic time estimates and build in buffer.
- For schedules, respect the constraints the user gave (time, energy, deadlines) and keep it simple.
- For decisions, list the main options with pros, cons and a clear recommendation, noting what would change it.
- Keep plans short and scannable; avoid overwhelming the user with long lists.
